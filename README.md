# Research Datasets

Datasets I used for deep learning experiments during my PhD in Management Information Systems at Dong-A University. They are kept here so the experiments can be reproduced.

| File | Rows | What it contains |
| --- | --- | --- |
| `adult_train.csv`, `adult_test.csv` | 32,561 and 16,281 | The UCI Adult census data for income prediction. The first column is the label (1 for income up to 50K, 2 for above). |
| `train_tweet.csv`, `test_tweet.csv` | 1,000 each | Short English sentences labeled for sentiment (1 positive, 0 negative). |
| `Train.csv`, `Test.csv` | 794 each | English names and descriptions of Korean dishes, labeled into four categories. |

The Adult data comes from the UCI Machine Learning Repository. Please cite the original sources if you reuse these files.
